## Slide 01: Computer Network (part 1)
*definition* · Computer Science

- **Computer network**: A number of computers (nodes) connected by communication lines, allowing any two computers to communicate directly or…
- Nodes (computers, switches, routers) facilitate network communication
- Communication can be of various types
- Computers exchange any kind of information, such as program data or other content
- Other specialized uses include interconnected small computers

## Slide 02: Computer Network (part 2)
*example* · Computer Science

- Network can be used as a communication tool

- Direct computer-to-computer communication
