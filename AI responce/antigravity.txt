1.2 What Was Right but Poorly Grounded
The Three.js Deterministic 3D Canvas: Using Three.js for 3D spatial management, dynamic cameras, vector arrows, and trajectory paths was the right technical choice. The error lay in treating 3D as a photo-realistic or raw primitive engine rather than using it as a geometric substrate flattened by Non-Photorealistic Rendering (NPR) into a 2D explainer aesthetic.
Deterministic Physics Engine Driven by an LLM Gated Reasoner: Separating semantic extraction (LLM: "what is happening") from kinematic simulation (Python/Wasm: "how it mathematically behaves") is standard neuro-symbolic practice. The failure occurred downstream at the visual representation layer, not at the reasoning or physics layer.
Delta-Driven Scene Graph Updates: Parsing incremental updates from natural language is the correct paradigm for real-time discourse. However, the scene graph lacked a formal ontology for physical affordances, IK attachment points, and fallback representations.
1.3 The Core Root Problem

The system suffers from Representation Mismatch: Attempting to solve a 3D spatial, kinematic, and continuous-motion problem using 2D static image operations (emojis, AI sheets, web cutouts).

In 2D, camera rotation, occlusion, depth sorting, force vectors, and mechanical interactions require drawing thousands of discrete sprites.
In 3D, camera transforms, depth buffering, joint articulation, and vector projections are calculated automatically via standard matrix mathematics (

The Solution: Execute all logic, spatial arrangement, and skeletal animation in 3D, but pass the output through an NPR (Non-Photorealistic Rendering) Cel/Toon Shader pipeline. This yields the visual identity of a flat vector explainer (Kurzgesagt / TED-Ed) while retaining full 3D mechanical and spatial control.

DROP IMMEDIATELY:
Local image diffusion (SD-Turbo) on the Whisper machine.

5.1 Three.js Custom Toon & Outline Implementation
javascript
import * as THREE from 'three';
// 1. Quantized Two-Step Diffuse Lighting (GLSL Chunk)
export function createExplainerToonMaterial(hexColor, shadowColorHex = '#1a1a2e') {
  return new THREE.ShaderMaterial({
    uniforms: {
      uBaseColor: { value: new THREE.Color(hexColor) },
      uShadowColor: { value: new THREE.Color(shadowColorHex) },
      uLightDirection: { value: new THREE.Vector3(0.5, 1.0, 0.5).normalize() }
    },
    vertexShader: `
      varying vec3 vNormal;
      void main() {
        vNormal = normalize(normalMatrix * normal);
        gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
      }
    `,
    fragmentShader: `
      uniform vec3 uBaseColor;
      uniform vec3 uShadowColor;
      uniform vec3 uLightDirection;
      varying vec3 vNormal;
      void main() {
        float NdotL = dot(vNormal, uLightDirection);
        // Discrete step: flat vector shadow boundary
        float lightIntensity = smoothstep(-0.05, 0.05, NdotL);
        vec3 finalColor = mix(uShadowColor, uBaseColor, lightIntensity);
        gl_FragColor = vec4(finalColor, 1.0);
      }
    `
  });
}
// 2. Inverted Hull Vector Outline (Pass 2)
export function attachVectorOutline(mesh, outlineColor = 0x111118, thickness = 0.03) {
  const outlineMaterial = new THREE.ShaderMaterial({
    uniforms: {
      uThickness: { value: thickness },
      uColor: { value: new THREE.Color(outlineColor) }
    },
    vertexShader: `
      uniform float uThickness;
      void main() {
        vec3 transformed = position + normal * uThickness;
        gl_Position = projectionMatrix * modelViewMatrix * vec4(transformed, 1.0);
      }
    `,
    fragmentShader: `
      uniform vec3 uColor;
      void main() {
        gl_FragColor = vec4(uColor, 1.0);
      }
    `,
    side: THREE.BackSide
  });
  const outlineMesh = new THREE.Mesh(mesh.geometry, outlineMaterial);
  mesh.add(outlineMesh);
}

This pipeline provides two crucial properties:

Geometric Leveling: High-poly, low-poly, and procedural CSG shapes look as if they were drawn by the same vector illustrator.
Camera Independence: The teacher can pan, zoom, and rotate the camera freely without sprite distortion or aliasing artifacts.

7.1 Pydantic JSON Schema for Scene Operations
python
from pydantic import BaseModel, Field
from typing import List, Optional, Literal
class ActorState(BaseModel):
    id: str = Field(description="Unique entity ID, e.g., 'man_1', 'box_1'")
    entity_type: str = Field(description="Normalized noun: 'man', 'box', 'electron', 'car'")
    label: Optional[str] = Field(None, description="Readable label shown on HUD")
    scale: Optional[float] = Field(1.0, description="Relative real-world scale multiplier")
class ActionOperation(BaseModel):
    subject_id: str
    verb: Literal["push", "pull", "throw", "walk", "collide", "orbit", "fall", "idle"]
    target_id: Optional[str] = None
    parameters: dict = Field(default_factory=dict, description="e.g. {'velocity': 5.0, 'angle': 45}")
class PhysicalRelation(BaseModel):
    source_id: str
    relation: Literal["on_top_of", "inside", "holding", "connected_to", "next_to"]
    target_id: str
class SceneDelta(BaseModel):
    op: Literal["ADD", "UPDATE", "REMOVE", "CLEAR"]
    entities: List[ActorState] = []
    actions: List[ActionOperation] = []
    relations: List[PhysicalRelation] = []
    camera_focus: Optional[str] = Field(None, description="Entity ID to focus/zoom")
    environment: Optional[Literal["classroom", "rough_surface", "space", "vacuum", "water"]] = None

11. Common Traps, Anti-Patterns & Engineering Guidelines
11.1 What NOT to Do (Architectural Anti-Patterns)
Never Let the LLM Write Render Code: Do not instruct the LLM to emit Three.js, Canvas2D, or Manim code at runtime. Even high-tier models introduce syntax errors, undefined variables, and inconsistent coordinate assumptions that break real-time execution. The LLM must output only structured data deltas.
Avoid Generating Multi-View Sprite Sheets: Do not attempt to generate 2D character sheets from diffusion models and slice them for animation. You will spend months fighting joint alignment issues, perspective distortion, and style drift.
Do Not Poll the Backend: Use bi-directional WebSockets. The client should never poll the backend for state updates.
Never Block Whisper's GPU Pipeline: Do not allocate PyTorch tensors or run other ML inference tasks on the laptop's GPU while faster-whisper is listening. This triggers VRAM swapping, increasing transcription latency from
