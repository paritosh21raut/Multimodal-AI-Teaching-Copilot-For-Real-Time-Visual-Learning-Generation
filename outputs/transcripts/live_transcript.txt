Today we are going to discuss computer networks, a computer network is a collection of interconnected devices that can communicate with each other. Networks allow us to share resources like files, Windows Internet Connections. Now let's discuss network topology, start topology through all devices through a central switch with one cable fails only that device affected. Bus topology uses a single cable to connect all devices. Now let's discuss TCP. TCP is a connection-oriented protocol. TCP provides reliable data transmission through acknowledgments. For example, TCP uses a three-way handshake to establish connection before it is transferred. UDP is a connectionless protocol unlike TCP UDP does not guarantee delivery. However, UDP is faster because it does not wait for acknowledgments TCP is used.
